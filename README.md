# ✦ MyGoals — Personal Goals Tracker

A clean, minimalist, responsive single-page web app to track and accomplish your personal goals with progress tracking and persistent browser storage.

Designed with the warm pastel palette from [Color Hunt](https://colorhunt.co/palette/ffced8ffddddfff4deffe8c4).

---

## ✨ Features

- **🎯 Single Clean Page**: Everything on one seamless screen — no nested boxes or cluttered cards.
- **📊 Real-time Goal Progress**: Track your completion percentage and accomplishments dynamically.
- **✅ Goal Management**:
  - Add any goal you want to achieve.
  - Checkbox to strike through completed goals.
  - Filter tabs: **All**, **Pending**, and **Completed**.
  - Delete goals you no longer need.
  - Clear all completed goals in one click.
- **💾 Persistent Storage**: All goals stay saved in your browser's `localStorage` so they remain after closing or reloading.
- **📱 Fully Responsive**: Optimized for desktop and mobile screens with touch-friendly tap targets and no iOS zoom.
- **🎨 Custom Logo**: Displays your custom logo and favicon.

## 💻 Local Preview

Run a local server:

```bash
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploy to GitHub Pages

1. Push this repository to GitHub:
   ```bash
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** → **Pages**
   - Under **Build and deployment**, set **Source** to `Deploy from a branch` and select `main`
   - Click **Save**
3. Your site will be live instantly!
